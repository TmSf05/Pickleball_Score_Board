# Pickleball_Score_Board
Creating a Score Board for Pickleball game to help players in scoring system

Project Name: Pickleball Score Board 

Tech Stack: Flutter, Dart, Material Design 3

Overview:
A cross-platform mobile and web application built with Flutter to manage pickleball match scoring. This app addresses the common pain point of mental math during fast-paced rallies by providing a digital, visual record of the game state.

Key Features:
1. Standard Rule Compliance:** Implements official USA Pickleball scoring rules, including "win by 2" mechanics after reaching 11 points.
2. Server Tracking:** Manual toggle for Server 1/Server 2 to ensure accurate call-outs (e.g., "4-3-2").
3. Intuitive UI:** Large, touch-friendly buttons for rapid input during play, with distinct color coding for Team A (Blue) and Team B (Red).
4. Real-Time Call Display:** Prominently displays the current verbal call at the top of the screen for quick reference.
5. Responsive Design:** Built with Flutter Web support, allowing it to run seamlessly in browsers via DartPad or as a standalone PWA.

Why Flutter?
This project demonstrates Flutter’s capability to create performant, native-like experiences from a single codebase. It utilizes `StatefulWidget` for efficient local state management and Material 3 components for a modern aesthetic.
